# Safia Schedule v16.2 Employee Rating Stable

Добавлено в недельный рейтинг сотрудников:
- индивидуальный процент посещаемости;
- отдельный показатель «Заменяли» — сколько раз вместо сотрудника выходил другой;
- отдельный показатель «Сам заменял» — сколько раз сотрудник сам выходил на замену;
- количество FULL;
- автоматические предупреждения при частых заменах, невыходах, ранних уходах и высокой нагрузке.

Неотмеченные смены не считаются как невыход и не снижают индивидуальный процент посещаемости до тех пор, пока менеджер не поставит статус.

Логика v16.1 «Не вышел → выбрать замену / без замены» сохранена.
