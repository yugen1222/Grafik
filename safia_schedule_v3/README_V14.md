# Safia Schedule v14 Stable

Главное обновление — защита Firebase от случайного обнуления.

- сайт не создаёт пустую базу автоматически;
- перед каждой записью проверяются сотрудники, недели, график и штатка;
- если основной state исчез, сайт ищет последнюю корректную копию в backups и восстанавливает её;
- если корректной копии нет, запись полностью блокируется;
- перед изменением создаётся резервная копия;
- транзакция отменяется, если Firebase во время записи стал пустым или повреждённым;
- данные разных устройств объединяются через безопасную transaction, а не полную перезапись узла.

Перед загрузкой версии рекомендуется один раз сделать Export JSON в Firebase.
