# Safia Schedule v10

Обновление встроено прямо в основной `app.js`; отдельный patch-файл не нужен.

Добавлено:
- фильтры контроля нагрузки для администратора;
- фильтр по ФИО, должности, смене, статусу и датам запрета;
- менеджер выбирает себя в левом меню и видит посещаемость только своей панели;
- отмена ошибочной отметки посещаемости;
- замена может подбираться из любых смен по навыку и ограничениям нагрузки;
- текущие ключи Firebase и структура данных сохранены.

Загрузка: замените файлы проекта в GitHub содержимым этой папки и сделайте Commit.
Перед обновлением рекомендуется экспортировать JSON из Firebase.
