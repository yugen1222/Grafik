# Safia Schedule v11

Что исправлено и добавлено:

- Исправлена панель 3-й смены: использован правильный ключ `shift3`, поэтому ночной менеджер больше не получает пустую посещаемость.
- Менеджеры фильтруются по своей панели: филиал 1/2/3 смена или обслуживание 1/2 смена.
- Администратор может явно закрепить выбранного менеджера за одной из пяти панелей в разделе «Посещаемость».
- Замены по-прежнему предлагаются из любых смен, но проходят проверки навыка, времени, 17 часов и ограничений фуллов.
- В карточке сотрудника можно выбрать несколько дней и:
  - поставить выходные;
  - не назначать смену только на выбранные дни;
  - вернуть сотрудника в график;
  - выбрать всю неделю.
- После установки выходных, удаления или восстановления назначений появляется красное уведомление:
  - если сотрудников стало меньше штатки — «выходных слишком много»;
  - если сотрудников больше штатки — «выходных слишком мало».
- На рабочем графике постоянно показывается красный блок с нарушениями штатки текущей панели.

Обновление не меняет ключ Firebase и не очищает существующие данные.
Перед загрузкой всё равно рекомендуется экспортировать JSON из Firebase.
