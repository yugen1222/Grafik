# Safia Schedule v12

Добавлен KPI пяти менеджеров в процентах.

Формула из 100%:
- составление графика — 40%;
- соблюдение графика — 20%;
- работа с заменами — 15%;
- контроль нагрузки — 15%;
- ведение посещаемости — 10%.

Менеджер подтверждает готовый график. Администратор видит отдельную страницу «KPI менеджеров» и может скачать KPI в Excel. Места не используются — показывается индивидуальный процент каждого менеджера.

Структура Firebase не очищается. Новые данные сохраняются в `weeks/<week>/managerKpi`.
