# Safia Schedule v16.4 Manager / Управляющий Stable

- Старт: Менеджер или Управляющий.
- Менеджер: без пароля, сразу выбирает себя и работает в своей панели.
- Управляющий: вход по паролю, сразу полная управляющая панель.
- Никакого дополнительного выбора роли после входа управляющего.
- Управляющий может открыть любую менеджерскую панель и вернуться одной кнопкой без повторного пароля.
- Внутреннее значение `admin` сохранено только для совместимости существующих функций.
- Функции v16.3/v16.2 (посещаемость, рейтинги, замены, FULL, Excel и т.д.) сохранены.
