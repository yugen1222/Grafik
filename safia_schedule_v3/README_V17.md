# Safia Schedule v17 — Employee Self-Service

Новая роль «Сотрудник» на стартовом экране.

## Сотрудник
- выбирает себя без доступа к менеджерской/управляющей панели;
- выбирает выходные на следующую доступную неделю до четверга 23:59;
- выходной блокируется, если после него штатка по его позиции/смене станет ниже нормы;
- отмечает «Могу выйти» и отдельно «Могу FULL»;
- сохраняет номер телефона для вызова на замену;
- не может менять должность и постоянную смену;
- отправляет выбор менеджеру.

## Менеджер / Управляющий
- новый раздел «Выбор сотрудников»;
- видно: кто выбрал, кто не выбрал, кто может выйти, кто может FULL, телефоны;
- фильтры по статусу и поиск;
- при клике на пустую ячейку графика открывается шпаргалка: сначала «Могу выйти», затем «Могу FULL», затем остальные;
- сотрудники, запросившие выходной, из шпаргалки исключаются;
- при постановке сотрудника сохраняются прежние проверки навыков, пересечений, 17 часов и FULL-лимитов.

Все данные хранятся в существующем Firebase state. Удалять или пересоздавать Firebase не требуется.
