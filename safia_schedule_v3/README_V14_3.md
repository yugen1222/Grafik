# Safia Schedule v14.3 Employee Recovery

Аварийная версия для восстановления сотрудников из сохранённого Firebase Export JSON.

- Если в Firebase меньше 10 активных сотрудников, восстанавливается резервный список.
- Записывается только `state/employees`; недели, штатка, история и посещаемость не перезаписываются.
- Если Firebase недоступен, сотрудники всё равно отображаются локально.
