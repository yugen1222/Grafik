# Safia Schedule v8

Обновление рабочего графика.

Добавлено:
- поиск сотрудников по ФИО;
- активные назначения сверху;
- итог/штатка по каждому дню;
- категория «Стажёр»;
- добавление сотрудника через «+» только при наличии навыка;
- точное время начала и окончания;
- несколько зон/смен в один день до 17 часов без пересечений;
- комментарии к назначению и история комментариев;
- сохранена совместимость с Firebase и ключом safiaScheduleV6.

Перед обновлением рекомендуется экспортировать JSON из Firebase.
