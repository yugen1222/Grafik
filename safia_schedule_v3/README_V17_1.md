# Safia Schedule v17.1 — Clean Week

Исправление создания следующей недели.

- Выходные прошлой недели больше не переносятся.
- Если сотрудник был выходной в определённый день прошлой недели, в новой неделе он возвращается в свою обычную должность и постоянную смену.
- Рабочие назначения прошлой недели копируются.
- Сотрудники, которые были специально оставлены без назначения, не начинают автоматически заполнять все дни.
- Пожелания сотрудников (выходной / могу выйти / FULL) остаются привязаны только к своей неделе.
- Если следующая неделя уже была автоматически создана старой версией и её ещё не редактировали, v17.1 безопасно пересоберёт только её график, сохранив штатку и пожелания сотрудников.
- Уже редактированные недели не очищаются автоматически.
