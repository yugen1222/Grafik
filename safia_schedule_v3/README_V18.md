# Safia Schedule v18 — Availability & protected staffing

## Что нового
- Сотрудник выбирает выходной, и он сразу отображается в графике следующей недели.
- Выходной блокируется, если после него людей станет меньше минимально допустимой штатки.
- По умолчанию допуск: штатка минус 1; управляющий может настроить допуск отдельно по должности и смене.
- «Могу выйти» можно отметить одновременно с выходным: это означает, что сотрудника можно вызвать при необходимости.
- Отдельно доступны «Могу FULL» и собственный интервал работы, например 18:00–02:00.
- Менеджеру список тех, кто не выбрал выходной, показывается отдельно по 1/2/3 смене.
- Менеджер может назначить выходной за сотрудника; защита штатки работает и при этом.
- Шпаргалка при добавлении сотрудника сортирует кандидатов: могу выйти → FULL → своё время → остальные. Жёсткий выходной без готовности выйти исключается.
- Телефон сотрудника отображается в шпаргалке.

## Важно
Данные сохраняются в существующей Firebase. Удалять или очищать базу не нужно.
