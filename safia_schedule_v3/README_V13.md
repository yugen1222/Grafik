# Safia Schedule v13 Stable

Главное изменение — безопасная cloud-first синхронизация.

- Рабочие данные загружаются только из Firebase Realtime Database.
- До завершения загрузки показывается экран «Загрузка базы», пустая панель не рисуется.
- Новый телефон или пустой браузер не может затереть облачную базу.
- Сохранение выполняется как разница изменений внутри Firebase transaction: изменённая штатка, день графика или сотрудник не перезаписывают остальные разделы.
- Роль, выбранная неделя и менеджер сохраняются локально только как настройки интерфейса.
- Перед изменениями создаются облачные резервные копии; хранится до 20 копий.
- Реестр удалённых сотрудников продолжает очищать их из графика, посещаемости и замен.
- Структура weeks / schedule / staffing / attendance / employees и KPI сохранена.

## Установка
1. Сначала Firebase → Realtime Database → Export JSON.
2. Замените файлы проекта содержимым архива.
3. Сделайте Commit и дождитесь Deploy.
4. После открытия дождитесь статуса «Онлайн · данные загружены».

Не удаляйте данные в Firebase и не импортируйте пустой JSON.
