# Safia Schedule v11.2

Исправления стабильности:

- открытая страница рисуется сразу; больше не создаются одновременно все тяжёлые панели;
- локальные данные показываются до подключения Firebase;
- добавлен индикатор «Сохранено / сохраняется / нет связи»;
- штатка получила отдельную версию и не заменяется старой пустой копией;
- при создании следующей недели штатка копируется из предыдущей недели;
- выходные по-прежнему не переносятся в новую неделю;
- текущий ключ Firebase и структура данных сохранены.

Перед обновлением рекомендуется один раз экспортировать JSON Firebase.
