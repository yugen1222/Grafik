# Safia Schedule v16 — Human-Factor Safe

Основные изменения:

- Стартовый экран: Менеджер / Администратор.
- Администратор защищён паролем. Пароль по умолчанию: `Safia2026!`.
- Менеджер входит без пароля и выбирает себя.
- Менеджер больше не может случайно переключиться в админ-панель.
- Посещаемость менеджера всегда открывается на сегодняшней дате и на фактической текущей неделе, даже если он составлял следующую неделю.
- При выходе из посещаемости возвращается неделя, которую менеджер планировал.
- Менеджер может добавить сотрудника, но новый сотрудник не расставляется автоматически по всем дням.
- Пустые дни показываются как «Не назначен / + Назначить».
- Поиск на рабочем графике ищет сотрудника по всем сменам и зонам.
- Карточка сотрудника показывает все назначения на неделю, включая FULL, другую зону, замену и выходной.
- Окончательное удаление сотрудников остаётся в админ-панели.

## Пароль администратора
