# Safia Schedule v12.1 Emergency Stable

Исправлена критическая синхронизация Firebase.

- Первый снимок Firebase всегда загружается, даже если `updatedBy` совпадает с текущим браузером.
- Новый или пустой браузер не может записать пустое состояние до первого чтения Firebase.
- Убрано автоматическое восстановление локальной штатки поверх более новой облачной.
- Запись выполняется транзакцией; более новая облачная копия не затирается старой.
- Перед изменениями автоматически хранится до 10 резервных копий в `backups`.
- Удалённые сотрудники объединяются через общий реестр удаления и не возвращаются со старого устройства.
- При смене роли данные перерисовываются без обязательного обновления страницы.

Важно: версия предотвращает будущие потери. Уже удалённые данные можно восстановить только из Firebase Backups/экспорта или из localStorage устройства, где они ещё сохранились.
