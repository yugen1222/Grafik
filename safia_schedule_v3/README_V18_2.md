# Safia Schedule v18.2

Исправление назначения выходных сотрудниками.

- Выбранный сотрудником выходной теперь принудительно синхронизируется с рабочим графиком.
- При нажатии «Отправить менеджеру» выполняется повторная синхронизация перед сохранением в Firebase.
- Уже отправленные выборы из v18/v18.1 автоматически восстанавливаются при открытии недели менеджером.
- Если менеджер вызывает сотрудника в его выбранный выходной через шпаргалку, создаётся явное исключение и назначение не удаляется автоматической синхронизацией.
- Пожелание «Могу выйти» при этом остаётся видимым менеджеру.
