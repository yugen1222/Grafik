# Safia Schedule v14.2 Stable Fix

Исправлена критическая ошибка `public/index.html`: HTML-документ был продублирован дважды, из-за чего в странице создавались повторные элементы с одинаковыми ID и JavaScript мог запускаться два раза. Это приводило к пустым разделам, нулевым сотрудникам и нестабильной загрузке Firebase.

В v14.2:
- в `index.html` оставлен только один документ;
- Firebase и `app.js` подключаются один раз;
- обновлены версии CSS/JS для сброса кэша браузера;
- сохранена защита Firebase v14.1.
