# Safia Schedule v16.1 Attendance Stable

- Возвращён процент посещаемости за день и неделю.
- «Ушёл раньше» считается как вышедший для процента посещаемости, но остаётся отдельным нарушением для KPI.
- «Не отмечено» не считается как «Не вышел».
- При нажатии «Не вышел / замена» сначала выбирается: подобрать замену или зафиксировать невыход без замены.
- Замена продолжает проверяться по навыку, пересечению времени, лимиту 17 часов и ограничениям фуллов.
