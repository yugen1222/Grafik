# Safia Schedule v16.3 Access Switcher Stable

- Стартовый экран теперь полностью отдельный и скрывает рабочее приложение до выбора роли.
- Администратор входит по паролю и остаётся в admin-сессии.
- В админ-панели кнопка «Сменить режим» позволяет открыть любую менеджерскую панель.
- При просмотре менеджера администратор видит кнопку «Вернуться в админ-панель» и не вводит пароль повторно.
- Можно сменить менеджера без выхода из admin-сессии.
- Обычный менеджер не получает админ-права и может только сменить менеджера или выйти к стартовому экрану.
- Все функции v16.2 (посещаемость, замены, рейтинг сотрудников, FULL, Excel и т.д.) сохранены.
